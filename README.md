# Lotto 게임 기능 요구사항

- 구입 금액 입력
- 구매 가능한 로또 개수 계산
- 로또 번호 랜덤 생성 (6개, 중복 없음, 1~45)
- 구매한 로또 번호 출력
- 당첨 번호 입력 (6개)
- 보너스 번호 입력 (1개, 당첨 번호와 중복 없음)
- 입력값 검증 (숫자 범위, 중복 체크)
- 로또 당첨 결과 확인 (등수 판정)
- 등수별 당첨 통계 계산
- 총 수익률 계산
- 결과 출력 (당첨 통계 + 수익률)

1. 구입금액 입력 및 테스트 완료 srp 고민
2. 로또번호 생성 
3. 당첨 번호 입력 
4. 보너스 번호 입력 
5. 당첨통계 
   지금 반대로 나옴
6. 총 수익률
